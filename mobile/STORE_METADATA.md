# Store metadata

## App name
Meal Planner

## Short description
Plan calm weeks, save favorite recipes, and shop from one smart list.

## Full description
Meal Planner brings recipes, weekly planning, and groceries together in one focused kitchen companion. Save your own recipes, assign meals across the week, and generate an aggregated shopping list automatically. Your recent data remains available offline and syncs when connectivity returns.
